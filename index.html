Настройки IMU

Ориентация рассчитывается на STM32 по акселерометру и гироскопу. Страница отображает готовый кватернион; отдельного переключателя слияния больше нет.

При запуске платы и после подключения начинается автокалибровка. Оставьте плату неподвижной примерно на 4 секунды в любом положении, без вибраций. При движении окно измерений начинается заново. Медленное равномерное вращение может быть принято за смещение нуля.

Ожидание подключения.

gx/gy/gz — скорость с вычтенным нулём после калибровки. Курс относительный: без магнитометра остаточный дрейф возможен. Кнопка ниже задаёт нулевой курс только для модели, не меняя наклон и прошивку.
